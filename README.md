Hearth is an offline household budget site for one family: a November 2026 dashboard ($5,200 income, 28 transactions, 8 budgets, 4 savings goals, 10 bills), a transactions ledger with add/edit/delete saved on the device, budgets with progress bars and editable limits, savings goals you can contribute to, and a bills planner with paid toggles — all as plain static files with inline SVG charts and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in a browser. Everything (dashboard, transactions, budgets, goals, bills) is linked from the top navigation, and all figures are computed from the same November dataset, so the pages always agree.
